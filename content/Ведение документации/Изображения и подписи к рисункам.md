Все изображения оформляются **единообразно — в виде таблицы из двух строк**: в первой строке — изображение, во второй — обязательная подпись, начинающаяся с **«Рис.»**.

# Имена файлов, расположение и нумерация

- Имена изображений задаются **только цифрами**: `1.png`, `2.png`, `3.png` и т. д.
- Формат — **только PNG**.
- Изображения размещаются **по пути `media/<Раздел>/<Подраздел>/`** — в подпапке своего раздела (и подраздела, если он есть).
- **Для всех документов нумерация рисунков начинается с `1`.** Конфликты имён между документами решаются за счёт разделения по папкам `media/<Раздел>/<Подраздел>/`: в каждом документе свой диапазон начинается с `1.png`, но лежит в своей папке.
- Если в одном подразделе несколько документов и возможны конфликты имён, документы размещаются в отдельных подпапках внутри подраздела (например, `media/<Раздел>/<Подраздел>/<Документ A>/1.png`, `media/<Раздел>/<Подраздел>/<Документ B>/1.png`).

# Синтаксис рисунка (двустрочная таблица с подписью «Рис.»)

Путь к изображению указывается **с папкой раздела и подраздела**, как в документах репозитория:

```markdown
| ![[media/<Раздел 1>/<Подраздел 1.1>/1.png]] |
| :-----------------------------------------: |
|         **Рис. 1.** Название схемы          |
```

**Правила:**

- Таблица всегда состоит из **двух строк**: изображение → подпись.
- Выравнивание — **по центру** (`:---:`).
- Подпись **обязательна**, начинается с `**Рис. N.**` (номер с точкой), затем краткое название.
- Нумерация рисунков в подписи — **сквозная в пределах документа** (Рис. 1, Рис. 2, …), **начиная с 1** для каждого документа.
- В тексте перед таблицей или после неё — обязательная ссылка «(см. Рис. N)».
- После таблицы с рисунком — **обязательная пустая строка** (см. раздел 8).

**Пример в контексте:**

```markdown
Схема подключения приведена на Рис. 1.

| ![[media/Компоненты Smart-платформы/Модуль ArcNet-2/1.png]] |
|:---:|
| **Рис. 1.** Схема подключения |

Далее описаны действия по подключению.
```

# Таблицы с несколькими рисунками

Если в документе нужна **таблица, содержащая несколько рисунков** (например, сравнение вариантов, галерея состояний индикаторов, набор типовых схем) — она оформляется **не** как двустрочная таблица с подписью «Рис.». Для таких таблиц создаётся **отдельная папка с названием таблицы** внутри папки подраздела:

```text
media/<Раздел>/<Подраздел>/<название таблицы>/1.png
media/<Раздел>/<Подраздел>/<название таблицы>/2.png
...
```

**Правила:**

- Папка называется **по названию таблицы** (кратко, по-русски, через пробелы — как и остальные папки).
- Нумерация изображений внутри папки таблицы начинается **с 1**.
- В самой таблице изображения вставляются через `![[media/<Раздел>/<Подраздел>/<название таблицы>/1.png]]`.
- Двустрочная таблица с подписью `**Рис. N.**` для таких таблиц **не применяется** — подписи к отдельным изображениям даются в самой таблице (в соответствующей ячейке или столбце).
- После такой таблицы — **обязательная пустая строка** (см. раздел 8).

**Пример:**

```markdown

Состояния индикатора приведены в таблице ниже.

| Состояние | Индикация |
|:---------:|:---------:|
| Норма     | ![[media/Компоненты Smart-платформы/Панель MMI/Состояния индикатора/1.png]] |
| Авария    | ![[media/Компоненты Smart-платформы/Панель MMI/Состояния индикатора/2.png]] |
| Ожидание  | ![[media/Компоненты Smart-платформы/Панель MMI/Состояния индикатора/3.png]] |

Далее — описание действий.
```

# Чем отличаются два варианта

|Вариант|Когда применять|Путь к изображению|
|---|---|---|
|Двустрочная таблица с подписью `**Рис. N.**`|Один рисунок с подписью в документе|`media/<Раздел>/<Подраздел>/1.png`|
|Таблица с несколькими рисунками|Несколько изображений внутри одной таблицы|`media/<Раздел>/<Подраздел>/<название таблицы>/1.png`|
