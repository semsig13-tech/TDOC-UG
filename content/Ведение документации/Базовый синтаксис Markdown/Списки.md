- **Маркированный** — `-` (дефис, не звёздочка).
- **Нумерованный** — `1.`, `2.`, `3.` — для пошаговых инструкций.

```markdown
- Пункт первого уровня
- Следующий пункт
1. Первый шаг.
2. Второй шаг.
3. Третий шаг.
```

**Через интерфейс Obsidian:**

- Наберите `-` и пробел — получите маркированный список. Следующие строки автоматически продолжают список при нажатии Enter.
- Наберите `1.` и пробел — получите нумерованный список; Obsidian сам проставит следующие номера.
- Переключение между маркированным и нумерованным — через панель форматирования или повторный ввод маркера.
- Выход из списка — двойное нажатие Enter.
