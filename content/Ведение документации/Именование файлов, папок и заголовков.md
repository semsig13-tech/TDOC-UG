- Имена папок и файлов — **по-русски**, с заглавной буквы. Пробелы в именах **допускаются** (это норма для Obsidian).
- Подчёркивания используются в артикулах и именах компонентов: `СМ_15`, `ArcNet-2`.
- **Заголовок `#` не является заголовком страницы.** Заголовком страницы служит **имя файла** (оно отображается в навигации Obsidian и на портале).
- Заголовок `#` может:
  - **присутствовать в документе несколько раз** — это допустимо, если внутри страницы есть несколько равнозначных крупных блоков;
  - **не совпадать с именем файла** — название страницы задаётся именем файла, а `#` — только внутренней структурой.
- Рекомендуется использовать `#` для выделения **смысловых частей документа**, а не для дублирования заголовка страницы.
- **Имена изображений задаются только цифрами** — `1.png`, `2.png`, `3.png` и т. д. (см. раздел [[#Изображения и подписи к рисункам]]). Никаких латинских букв и слов в именах картинок.
- Имена файлов для скачивания — латиницей через дефис: `example.pdf`, `firmware-v1.bin`.

**Пример:**

```text
Файл:      <Документ A>.md
Заголовки внутри:
	# Общие сведения
	# Технические характеристики
	# Порядок подключения
```
